## 🏢 Overview

This project presents a **simulation and queueing analysis** of the **student attendance card-marking process** at a private class institute.

The study focuses on measuring **student waiting times**, **service durations**, **queue lengths**, and **counter utilization**, while identifying bottlenecks during peak arrival periods.

The private class operates with **three class batches per day** at **08:30 AM, 01:30 PM, and 04:30 PM**. Students arrive at the entrance before each batch to have their attendance cards checked and marked.

---

## 🎯 Performance Objectives

The study aims to:

1. **Reduce Waiting Time**

   * Minimize the time students spend waiting at the entrance.

2. **Increase Throughput**

   * Process more students before each class starts.

3. **Find Bottlenecks**

   * Identify where delays occur during the card-marking process.

4. **Use the Counter Efficiently**

   * Determine whether one counter is sufficient during peak periods.

5. **Improve Staff Allocation**

   * Assess whether an additional staff member or counter is required during busy periods.

---

## 📊 Dataset

The dataset contains **156 student check-in observations** collected across **2 operating days**, covering four class batches per day.

The dataset includes:

- Student record ID
- Session date
- Arrival time
- Queue length
- Service start time
- Attendance/document check completion time
- Payment completion time
- Service end time
- Waiting time
- Service duration
- Total process time
- Batch and counter information
- Remarks and exceptions
